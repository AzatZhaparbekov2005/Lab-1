# Описание компонентов

Названия компонентов совпадают с названиями на схеме `architecture.png`.

## Клиентский уровень (представление)

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| Покупатель (браузер) | Ищет объекты, запускает расчёт оценки, сравнивает объекты и формирует отчёт. Без этой роли система не имела бы основного потребителя результата | Браузер | React SPA (действия пользователя) |
| Владелец / риелтор (браузер) | Вводит и обновляет объекты и их параметры: это источник данных для расчёта. Без него в системе нет объектов | Браузер | React SPA |
| Эксперт-оценщик (браузер) | Корректирует результат расчёта и оставляет комментарий; нужен, потому что формула не учитывает всех особенностей объекта | Браузер | React SPA |
| Администратор (браузер) | Управляет пользователями, коэффициентами и ценами регионов; без него формулу нельзя настраивать без изменения кода | Браузер | React SPA |
| React SPA | Показывает формы, карточки объектов, результат расчёта и отчёты; отправляет запросы к API и показывает ответы. Без него пользователю пришлось бы отправлять запросы вручную | React, TypeScript | Backend (HTTPS, REST, JSON) |
| Состояние клиента | Хранит JWT-токен и состояние интерфейса (фильтры, открытые формы). Благодаря токену серверу не нужно хранить сессии (stateless). Данных БД и расчётов здесь нет | Память браузера / localStorage | React SPA |

## Серверный уровень (приложение, NestJS)

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| Auth + Guards | Проверяет подпись и срок JWT-токена и роль пользователя (RBAC) до выполнения любой логики. Без него любой пользователь мог бы вызвать любую операцию, например изменить коэффициенты | NestJS Guards, JWT | React SPA (вход), Controller, все модули |
| Controller | Принимает HTTP-запросы, проверяет формат данных (DTO) и передаёт их в Service. Отделяет работу с HTTP от бизнес-логики | NestJS Controllers, class-validator | Auth + Guards, Service |
| Service | Содержит бизнес-логику: порядок шагов расчёта, правила доступа к объектам. Без него логика оказалась бы в контроллерах и дублировалась | NestJS Providers | Controller, модули |
| Auth / Users | Регистрация, вход, хэширование паролей (bcrypt), выпуск JWT; хранение профилей и ролей | NestJS, bcrypt, JWT | ORM — Prisma, Auth + Guards |
| Properties | Создание, изменение, поиск и фильтрация объектов; получение координат и расстояния до города при добавлении объекта | NestJS | ORM — Prisma, Геокодер / карты |
| Valuation | Считает рыночную стоимость по формуле: берёт цены региона и коэффициенты, сохраняет оценку со снимком применённых значений; при устаревших ценах обновляет их у внешнего источника | NestJS | Properties, Reference, Attractiveness, ORM — Prisma, Источник рыночных цен |
| Attractiveness | Считает индекс привлекательности (0–100) как взвешенную сумму факторов и определяет категорию | NestJS | Valuation, Reference, ORM — Prisma |
| Reports | Формирует отчёты PDF по оценке и сравнению объектов. Без него результат нельзя сохранить и передать | NestJS, генератор PDF | Valuation, ORM — Prisma |
| Reference | Хранит и отдаёт справочники: коэффициенты, веса факторов, диапазоны допустимых значений; изменения доступны только администратору | NestJS | Valuation, Attractiveness, ORM — Prisma |
| ORM — Prisma | Единственная точка доступа backend к БД: преобразует вызовы модулей в SQL, управляет транзакциями. Без него SQL был бы разбросан по модулям | Prisma | Модули, PostgreSQL (SQL) |

## Уровень данных

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| PostgreSQL | Хранит пользователей, населённые пункты, объекты, параметры инфраструктуры, оценки, отчёты, отзывы, коэффициенты и цены. Ограничения целостности (внешние ключи, уникальность) защищают данные от ошибок | PostgreSQL | Только backend через ORM (SQL) |

## Внешние сервисы

| Компонент | Назначение | Технология | Взаимодействует с |
| --- | --- | --- | --- |
| Геокодер / карты | Превращает адрес или название села в координаты и считает расстояние до ближайшего города: этот параметр влияет на стоимость и индекс. Без него расстояние пришлось бы вводить вручную | Внешний API (Maps API) | Properties (HTTPS, JSON) |
| Источник рыночных цен | Поставляет базовые цены за сотку и за м² по регионам, на которых строится расчёт. Без него цены пришлось бы вносить вручную | Внешний API или открытые данные | Valuation (HTTPS, JSON) |
